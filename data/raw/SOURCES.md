# Источники данных урожайности пшеницы

Файл `yields.csv`: `region_id,year,yield_c_ha`. Единица: центнер с гектара (100 кг/га), пшеница (озимая и яровая вместе), все категории хозяйств.
Единица наблюдения: район (rayon) или город республиканского подчинения. Агрегаты (экономические районы, республика) не включены, чтобы не дублировать данные.

## Источник

Государственный комитет по статистике Азербайджана (State Statistical Committee), ежегодник «The Agriculture of Azerbaijan», таблица 2.187 «Yield of wheat, 100 kg/ha».

| Выпуск | Годы в таблице | URL | Дата получения |
|---|---|---|---|
| 2024 | 2020-2023 | https://www.stat.gov.az/menu/6/statistical_yearbooks/source/agriculture_2024.pdf (стр. 511-512 печатной нумерации) | 2026-11-18 |
| 2026 | 2022-2025 | https://www.stat.gov.az/menu/6/statistical_yearbooks/source/agriculture_2026.pdf (стр. ~504-505) | 2026-11-18 |

Страница со списком выпусков: https://www.stat.gov.az/menu/6/statistical_yearbooks/?lang=en

## Обработка

- Значения извлечены из PDF скриптом (pdfplumber), привязка числа к строке по вертикальной координате относительно английской подписи района. Текстовый режим pdftotext -layout смещает значения на строку, поэтому не использовался.
- Пересчёт «валовой сбор / площадь» не применялся: значения урожайности взяты как опубликованы.
- Годы 2022 и 2023 есть в обоих выпусках; значения совпали для всех строк таблицы (проверка выполнена скриптом) (проверка на согласованность извлечения). Для остальных лет значения взяты из единственного выпуска, где они есть.
- Названия районов: «Khojavend»/«Khojavand» и «Zangezur»/«Zangazur» приведены к написанию выпуска 2024.

## Покрытие

- 66 районов и городов, по 6 лет каждый (2020-2025), 396 строк. **Лет меньше 8: в плане использовать один предиктор.**
- Исключены единицы с пропусками («-») в опубликованных данных: Ganja city (2022, 2024, 2025), Dashkasan (2022), Khojavand (2021), Mingachevir city (2021-2025), Aghdara (нет 2022-2023, новый район).
- Выпуски 2022 и раньше (годы до 2019) по прямым ссылкам не найдены (сервер возвращает HTML-заглушку), поэтому ряд короткий.
- Низкие значения в ряде освобождённых районов (Jabrayil, Lachin, Zangilan, Kalbajar, Gubadli, Khojaly и др.) опубликованы официально; причины (освоение земель, а не погода) не проверялись, влияние на валидацию стоит проверить.

## Прочие просмотренные источники (данных для ряда не дали)

- IAMO TR_Azerbaijan.pdf: районного ряда урожайности пшеницы не найдено (поиск по тексту).

# Геометрия районов и маска пашни (Task 3)

## Границы

geoBoundaries gbOpen, AZE ADM2 (79 единиц, год представления 2020, сборка 2023-12-12). API: https://www.geoboundaries.org/api/current/gbOpen/AZE/ADM2/. Исходник границ geoBoundaries: Wikipedia (administrative divisions of Azerbaijan), лицензия CC BY-SA 3.0; при публикации карты нужна атрибуция. Скачивается кодом в `data/raw/cache/` (в git не коммитится).

Сопоставление: `region_aliases.csv` (`region_id,geometry_name`), составлено сверкой названий по реальному списку `shapeName`. Совпали все 66 id из `yields.csv`, ненайденных нет, исключений нет.

Решения по неоднозначным названиям:
- В ADM2 есть пары «City» и «District» для Shaki, Shusha, Yevlakh, Lankaran. В статистике для них один id без суффикса `-city` (города публикуются отдельными id только для Nakhchivan и Naftalan), поэтому `shaki`, `shusha`, `yevlakh`, `lankaran` сопоставлены с District (площади 2306/296/1278 км2 против 12-28 км2 у городов). Города Shaki, Shusha, Yevlakh, Lankaran City остаются без статистики и в карту не попадают.
- Geometry «Lankaran District» встречается в ADM2 дважды (542 и 608 км2, два несмежных полигона, оба соприкасаются с Masally). Принято: `load_regions` объединяет (dissolve) все полигоны с одним `geometry_name` в один регион. Что это именно две части одного района, подтверждено только совпадением названия, не независимым источником.
- Shusha: непонятно, относится ли значение статистики к району или к городу; выбран район (в нём есть пашня), допущение не проверено.

## Маска пашни

ESA WorldCover 2021 v200 (10 м), Microsoft Planetary Computer STAC, коллекция `esa-worldcover`, актив `map`, анонимный доступ через `planetary_computer.sign_inplace`. Класс 40 = Cropland. Кеш: `data/raw/cache/worldcover2021_cropland_az_100m.tif` (в git не коммитится).
Растр пересэмплирован до сетки 1/1200 градуса (около 71 x 93 м на широте Азербайджана; файл 4 МБ, смоук-запуск 134 с) методом mode (мода класса в ячейке) и хранится как uint8-растр классов (0 = нет данных), bbox 44.7-50.7 E, 38.3-42.0 N (чуть шире страны). Полигоны районов маской не обрезаются.
