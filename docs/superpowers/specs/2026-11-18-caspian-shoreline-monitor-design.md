# Монитор отступления берега Каспия у Азербайджана — дизайн

Дата: 2026-11-18. Статус: на утверждении. Заменяет направление «пшеница и засуха» (2026-11-18-wheat-drought-early-warning-design.md).

## Зачем
Цель владельца — первое место на Global Sustainability Challenge 2026–27 и «рабочий продукт». Предыдущая идея (индекс засухи для пшеницы) прошла строгую проверку «оставь один год» и не показала предсказательной силы (корреляция 0,10 и −0,06, ошибка не лучше простого тренда); результат воспроизведён независимым проверяющим и не является ошибкой кода. Подгонять индекс после просмотра результата нельзя, поэтому берётся задача, где сигнал физически сильный и проверяется по независимым данным.

Проект: открытый повторяемый монитор отступления береговой линии Каспия у Азербайджана по спутниковым снимкам, с проверкой по спутниковой высотометрии уровня моря, показывающий карту берега по годам и площадь обнажившейся суши.

Трек конкурса: «Adaptation & Resilience», направление «Water». Конкурс: Ignite до 22.11.2026 (описание проекта и видео на 2 минуты, готовит владелец), Build до 22.02.2027.

## Известное (разведка 2026-11-18)
- Снижение уровня Каспия подтверждено источниками; у побережья Азербайджана отступление берега видно на Апшероне ([Euronews](https://euronews.com/2026/05/15/the-worlds-largest-lake-is-shrinking-can-central-asian-nations-save-it-before-its-too-late), [тезисы EGU 2024](https://meetingorganizer.copernicus.org/EGU24/EGU24-14488.html): около 218 км² обнажённой суши в Кызылагаче по Landsat и Sentinel-1).
- Тема изучена: есть [работа по Куринской зоне](https://www.irsm.cas.cz/materialy/acta_content/2021_doi/Gasimov_AGG_2021_0035.pdf). Новизна идеи низкая; ценность проекта — открытый воспроизводимый инструмент с заранее заданной проверкой.
- Данные уровня: G-REALM (USDA/NASA), текстовые ряды из спутниковой высотометрии, Каспий присутствует; высоты относительные, в заголовках файлов даны поправки. Мареографические данные по Каспию в основном недоступны.
- Спутниковые архивы: Landsat Collection 2 (с 1980-х, 30 м) и Sentinel-2 (с 2017, 10 м) через Microsoft Planetary Computer без аккаунта.

## Цели
1. Годовая береговая линия Азербайджана (выбранные участки) за 2000–2025 из Landsat, текущая линия из Sentinel-2.
2. Проверенная связь «смещение берега — уровень моря» с заранее заданным критерием успеха (ниже).
3. Статическая карта: линия берега по годам, площадь обнажённой суши в км² по участкам, таблица «метров отступления на сантиметр падения уровня» для каждого участка.
4. Текст заявки и сценарий видео для Ignite (английский), без заявлений, не подтверждённых проверкой.
5. Журнал времени по этапам (оценка superpowers).

## Не цели
- Прогноз будущего уровня моря и сценарии «если уровень упадёт ещё на метр».
- Контакты с третьими лицами; выдуманные партнёры, пилоты, отзывы.
- Оценка ущерба в деньгах, мобильное приложение, сервер.
- Модели машинного обучения; другие культуры и темы (пшеничный проект остаётся в репозитории как архив).

## Антицели
- Заявлять корреляцию, не прошедшую заранее заданную проверку; подгонять критерий, участки или период после просмотра результатов.
- Выдавать общий тренд двух рядов за связь: оба ряда падают со временем, поэтому сырая корреляция тривиально высока (см. критерий).
- Скрывать слабые участки: если связь на участке не подтверждается, это пишется.

## Критерий успеха (заранее, не менять после просмотра результатов)
Для каждого участка и по всем участкам вместе, по ежегодным значениям за 2000–2025:
1. Основной: схема «оставь один год»; модель «уровень по смещению берега» должна иметь меньшую RMSE, чем модель «уровень только по линейному тренду во времени» (параметры обеих оцениваются только по обучающим годам).
2. Вторичный: корреляция Пирсона между годовыми разностями (первыми приращениями) смещения берега и уровня не ниже 0,5.
3. Вердикт «подтверждено» только при выполнении обоих; иначе «не подтверждено» или «частично» с причиной. Сырая корреляция публикуется отдельно с пометкой о тренде.
Сезон снимков фиксируется один для всех лет (чтобы убрать сезонный ход уровня около 30 см — значение проверить по данным G-REALM и записать), выбор сезона делается до просмотра связи.

## Подходы

Способ построения:
- **A. Landsat годовые композиты 2000–2025 + индекс воды (MNDWI), линия берега по поперечным профилям, проверка по G-REALM (выбран).** Длинный ряд (около 25 лет) снимает проблему «6 лет» прошлого проекта; Sentinel-2 используется для текущей карты и сверки.
- B. Только Sentinel-2 с 2017 года: выше разрешение, но около 9 лет и меньше изменений уровня; слабее для проверки.
- C. Sentinel-1 (радар): не зависит от облаков, но шумнее на мелководье и ветровых волнах; осложняет проверку; отклонён.

Участки: выбирает строитель по литературе (Кызылагач, Куринская зона, северо-восточный Апшерон) и пологости берега; список и причины фиксируются до анализа связи.

## Определения и правила (решения Claude после ревью; фиксируются до просмотра связи)
- **Смещение берега:** по участку — среднее по поперечным профилям знаковое расстояние линии воды от фиксированной опорной линии (положительное = отступление моря). Единица — метры. Годовая линия берега — по композиту выбранного сезона.
- **Модель и базовая модель:** по каждому участку отдельно. Модель: уровень = a + b·смещение. База: уровень = a + b·год. Оба обучаются только на обучающих годах схемы «оставь один год». Участки не сливаются в один пул; общий вердикт — по числу участков (ниже).
- **Уровень G-REALM:** среднее по датам внутри сезона композита того же года; нужно не менее 3 наблюдений в окне, иначе год пропускается. Используется единый относительный ряд продукта; проверяется на скачки между миссиями, результат записывается.
- **Период:** 2000–2025, либо самый длинный общий отрезок наличия уровня и снимков; решается один раз после скачивания G-REALM и до анализа связи. Если пригодных лет меньше 15 — остановка и возврат к владельцу.
- **Пропуски лет:** приращения считаются только между соседними доступными годами, через пропуск не считаются; схема «оставь один год» идёт по доступным годам.
- **Значимость:** дополнительно к r ≥ 0,5 требуется, чтобы нижняя граница 95%-ного бутстрэп-интервала r была больше 0 (серии коротки, приращения автокоррелированы). Вердикт участка «подтверждено» = оба порога + выигрыш RMSE у базы.
- **Общий вердикт:** «подтверждено» — не менее двух измеримых участков подтверждены; «частично» — один; иначе «не подтверждено». Участок измерим, если линия берега найдена не менее чем в 20 из 26 лет не менее чем на 80% профилей; неизмеримый участок публикуется как «не измерим» с причиной и не считается ни подтверждённым, ни опровергнутым. Не менее 3 участков, выбранных по правилу «пологий, без растительности и без дельтового заболачивания» до анализа связи; дельтовые участки допустимы, но помечаются.
- **Сезон снимков:** непрерывное окно из двух месяцев в июле–октябре с наименьшей медианной облачностью по метаданным сцен за весь период (воду, берег и уровень при выборе не смотрим); не менее 3 пригодных сцен на участок и год, Landsat 7 после сбоя SLC учитывается композитом.
- **Контроль линии берега:** сравнение Landsat и Sentinel-2 за общие годы 2017–2025; медианное расхождение по участку не более 30 м (один пиксель Landsat), иначе участок помечается. На карте показывается неопределённость не менее 30 м.
- **Заявка:** английский, по структуре предыдущего чернового текста (около 900–1200 слов); лимиты и обязательные разделы Ignite видны только в Challenge Hub после входа — владелец сверяет их при загрузке.
