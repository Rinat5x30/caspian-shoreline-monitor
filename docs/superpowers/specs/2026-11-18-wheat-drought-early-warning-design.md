# Раннее предупреждение о засухе для пшеницы в Азербайджане — дизайн

Дата: 2026-11-18. Статус: на утверждении.

## Зачем
Цель владельца — первое место на Global Sustainability Challenge 2026–27 (тема 02 «Adaptation & Resilience», направление «Food resilience»). Параллельно владелец проверяет, насколько процесс superpowers подходит для 48-часовых хакатонов.

Проект: районная карта риска засухи для пшеницы в Азербайджане по спутниковому NDVI, осадкам и температуре, с честной проверкой на официальной статистике урожайности за прошлые годы.

## Что известно о конкурсе (с сайта, 2026-11-18)
- Команда 1–6 студентов, хотя бы одному 18+ к 1.01.2027. Владелец учится в Азербайджане.
- Ignite (до 22.11.2026): состав команды, описание проекта, 2-минутное видео. Регистрация закрывается 22.11, 23:59 UTC.
- Build (дек 2026 – 22.02.2027): документированное решение с отзывами пользователей; 10 минут презентации и демо прототипа.
- Критерии жюри не опубликованы. Ответы в FAQ не загрузились.
- Призёры 2025–26 объединяет: проверка на реальных данных или в лаборатории, конкретная проблема с цифрами, у большинства — реальный партнёр или пилот.

## Цели
1. Сильная заявка на Ignite к 22.11: описание проекта и сценарий 2-минутного видео.
2. Рабочий прототип: карта риска по районам/регионам Азербайджана плюс отчёт о проверке.
3. Одна честная цифра точности, получаемая проверкой «оставь один год» на официальной статистике.
4. Журнал времени по этапам для оценки superpowers.

## Не цели
- Письма и контакты с министерствами, организациями или фермерами (владелец отказался).
- Машинное обучение, симуляция роста культур (AquaCrop), мобильное приложение, платежи.
- Несколько культур (только пшеница).

## Антицели (провал, даже если всё работает)
- Заявлять точность, которую проверка не подтвердила.
- Придумывать партнёров, письма о намерениях или отзывы пользователей. Заменители помечаются как план, а не как факт.
- Прятать слабость данных: если проверка грубая (по регионам, мало лет), это пишется прямо.

## Ограничения
- Двое: владелец и Claude. Третьи лица не участвуют.
- Только открытые данные без платных аккаунтов.
- Срок: заявка к 22.11. Тестовый бюджет на прототип — 48 часов.
- Регистрацию в Challenge Hub владелец делает сам: это его аккаунт.

## Подходы

Направление (выбрал владелец: C):
- A. Тепловая устойчивость, перегрев Баку. Нет наземных данных для проверки.
- B. Водный стресс, водохранилища. Мало официальных данных об уровнях.
- **C. Продовольственная устойчивость, засуха и урожай пшеницы.** Есть проверка по официальной статистике.

Способ построения (выбор Claude, владелец делегировал):
- **1. Индекс засухи без ML (выбран).** Отклонения NDVI, осадков (CHIRPS) и температуры (ERA5) от нормы; простая объяснимая регрессия на аномалию урожайности; проверка «оставь один год». Честная проверка при малом числе лет, укладывается в срок.
- 2. Градиентный бустинг: около 8 лет на регион, переобучение.
- 3. Симуляция AquaCrop: не укладывается в 48 часов.

## Решения Claude (владелец может отменить)
- Python для анализа. Данные: Microsoft Planetary Computer (Sentinel-2/MODIS), CHIRPS, Open-Meteo/ERA5 без аккаунтов.
- Веб-вьюер: статическая HTML-карта (Leaflet) на заранее посчитанных GeoJSON, без сервера. Решение изменено после ревью: жюри смотрит видео и демо, сервер только добавляет риск. Публикация ссылки — отдельное решение владельца.
- Результат дополняется текстом заявки и сценарием видео.
- Порядок работ: сначала текст заявки и сценарий видео (дедлайн 22.11), затем данные и проверка. Цифра точности идёт в заявку, если готова к 21.11; иначе заявка описывает метод и предварительный результат, без неподтверждённых цифр.

## Проверка (решения Claude после ревью)
- Цель: аномалия урожайности в процентах после удаления линейного тренда.
- Меры: корреляция Пирсона, RMSE, доля верно угаданных лет с урожайностью ниже нормы. Схема «оставь один год».
- Порог заявления: заявляется только то, что показала проверка. Слабый сигнал публикуется как слабый; это допустимый честный результат.
- NDVI: MODIS (с 2000 г.) для истории, Sentinel-2 по желанию. Цель — не менее 8 лет. Если лет меньше, один составной предиктор вместо трёх.
- Форма данных: допустим ручной перенос из PDF/XLS и пересчёт «валовой сбор / площадь». Если за ~6 часов нет даже региональной серии урожайности, остановка и возврат к владельцу.
- Карта показывается на том уровне, на котором проведена проверка. Маска пахотных земель: ESA WorldCover. Границы: geoBoundaries.
- Источники без платных аккаунтов. Бесплатная регистрация (Earthdata/Copernicus) возможна только если станет блокером, тогда спрашиваю владельца.
- Время по этапам записывается в `docs/superpowers/timing-log.md`.

## Главный риск: данные урожайности
По результатам разведки: официальные данные по районам существуют (их использовали исследователи IAMO), но готовой таблицы для скачивания на stat.gov.az найти не удалось. FEWS NET указывает, что данные дают по «посевным регионам», а не по 67 районам.

Порядок: первым делом найти и выгрузить серию урожайности. Если районной серии нет, проверка делается по регионам, ограничение явно описывается в заявке. Если нет и региональной серии, проект останавливается и возвращается к владельцу.
