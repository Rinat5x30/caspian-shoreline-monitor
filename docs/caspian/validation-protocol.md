# Протокол проверки: береговая линия против уровня моря

Записано 2026-11-19 01:42 (локальное время), до написания кода проверки и до какого-либо контакта с рядом уровня G-REALM в рамках этой проверки.

Заявление: ни контролёр, ни ревьюеры не видели никакой связи «смещение берега - уровень моря». Все решения ниже приняты до этого. Критерий взят из спецификации (раздел «Критерий успеха», «Определения и правила»); здесь он сделан операциональным. При расхождении с формулировками плана действуют эти решения. Отрицательный результат допустим и будет опубликован как есть.

## Решения

(a) Знак. D положительно при отступлении моря; при отступлении уровень падает. Поэтому r_diff := Pearson(Delta D, -Delta L), ожидается положительное. Спецификация говорит «не ниже 0,5» без знака; это уточнение соглашения о знаке, физический смысл не менялся.

(b) Приращения только между СОСЕДНИМИ календарными годами, где оба значения конечны; через пропуски не считаются.

(c) Бутстрэп: процентильный 95 % интервал (2,5 %; 97,5 %), N_BOOT = 2000, ресэмплинг пар приращений независимо с возвращением, фиксированный seed (по умолчанию 0). Ресэмплы с нулевой дисперсией в любом из рядов считаются вырожденными и исключаются; если вырожденных больше 5 %, ci_low = NaN и участок не подтверждён. Блочный бутстрэп (скользящие блоки длины 3) только ВТОРИЧНЫЙ.

(d) Leave-one-year-out по общим годам, где конечны и D(y), и L(y). Обе модели обучаются только на обучающих годах: модель L = a + b*D, база L = a + b*год. Предсказывается отложенный год; RMSE считается по всем отложенным предсказаниям вместе. MIN_COMMON_YEARS = 10, иначе вердикт участка «not_measurable» с причиной.

(e) Вердикт участка: «confirmed» тогда и только тогда, когда RMSE(модель) < RMSE(база) И r_diff >= R_DIFF_MIN (0,5) И r_diff_ci_low > 0. «not_measurable», если ряд берега не измерим (shoreline.is_measurable ложно) или общих лет меньше MIN_COMMON_YEARS. Иначе «not_confirmed» (причина называет невыполненные условия). Общий вердикт: «confirmed» при >= 2 подтверждённых участках; «partial» при ровно 1; иначе «not_confirmed». L(y) = level.season_level(levels, y, (7, 8), min_obs=3) по закоммиченному файлу G-REALM, сезон из season.json; D(y) = НЕВЗВЕШЕННЫЙ ряд смещения участка (Task 6).

(f) ВТОРИЧНЫЕ анализы, публикуются рядом с вердиктом, но не меняют его: сырой (недифференцированный) Pearson r между D и -L (с пометкой, что оба ряда имеют тренд); взвешенный вариант смещения; вариант с фиксированным подмножеством «всегда присутствующих» профилей (непустых во все годы); чувствительность к порогу с фиксированными порогами MNDWI 0,0; 0,1; 0,2, пересчитанными по сохранённому MNDWI (вода = valid & mndwi > t; берег и смещение пересчитываются по правилам Task 6; затем то же вычисление вердикта, только как чувствительность); блочный бутстрэп-интервал; gizilaghaj без 2024-2025 (правое цензурирование); для участка с вердиктом «confirmed» отступление на 1 см падения уровня = 0,01/|b| м по полной выборке L = a + b*D (b в метрах уровня на метр смещения), НЕ для других участков.

(g) Реальный прогон ровно ОДИН раз скриптом scripts/run_caspian_validation.py; вывод (все SiteReport, общий вердикт, вторичные таблицы, ряды D и L по участкам и годам) сохраняется и коммитится сразу как docs/caspian/validation-run.txt. Повторный запуск допускается только для байт-в-байт воспроизведения (записывается sha256). После прогона не меняются параметры, определения, участки, годы, сезон, пороги.

Первый контакт с реальным рядом уровня - единственный реальный прогон. До него ряд уровня используется только в офлайн-тестах на синтетике.
